# Kelime Tahmin Oyunu

Python ve Tkinter kullanılarak geliştirilmiş basit bir kelime tahmin oyunudur.

## Özellikler

- Rastgele kelime seçimi
- Harf tahmin sistemi
- 6 yanlış tahmin hakkı
- Türkçe karakter desteği
- Grafik kullanıcı arayüzü
- Kazanma ve kaybetme bildirimleri

## Kullanılan Teknolojiler

- Python
- Tkinter

## Çalıştırma

```bash
python kelime_tahmin_oyunu.py
